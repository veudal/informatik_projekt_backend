
# Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/veudal/informatik_projekt_backend.git
   ```

2. Configure **JDK 21** in IntelliJ (click the JDK setup notification and select Java 21).

3. Change Maven settings:
    - Press `Ctrl + Alt + S`.
    - Navigate to **Build, Execution, Deployment → Build Tools → Maven**.
    - Change **Maven home path** from `Use Maven wrapper` to `Bundled Maven 3`.
